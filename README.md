# Always-On-Electrical

Website for Always On Electrical — Peter Agnew's electrical contracting
business covering Dublin, Wicklow and Kildare, Ireland.

**Status:** In development. Branding and page designs are done and the static site is built in `site/`;
the PHP callout-request handler for Eirhost cPanel hosting is next.

See [`docs/always-on-electrical-handoff.md`](./docs/always-on-electrical-handoff.md)
for full project scope, features, branding direction, and technical requirements.

## Layout

| Folder | What is in it |
| --- | --- |
| `docs/` | The project handoff document. |
| `brand/` | Design canvas source: the artboard generators and the nine artboards. See `brand/README.md`. |
| `assets/3d/` | Peter's logo and button models (OBJ, MTL, GLB), the reference for the mark. |
| `site/` | The website: templates and assets in `site/src`, the built site in `site/dist` (upload that to `public_html`). See `site/README.md`. |

The design canvas itself is at https://claude.ai/code/artifact/23d1a01f-e8fb-4149-b853-07faaa4651c7
